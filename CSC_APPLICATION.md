## Key Technical Decisions I Made
1. Split monolith → microservices for scalability
2. Implemented Row-Level Security at DB level for data isolation
3. Added AI rate limiting to prevent abuse
4. Chose Supabase for RLS + auth + storage in one platform
5. Used PWA patterns for offline-first mobile experience
